# Contribution workspaces

[Profile](README.md) · [Upstream evidence](UPSTREAM.md) · [Original projects](PROJECTS.md)

These public forks are working copies of upstream projects, **not original projects
or claims of authorship of their full codebases**. Repository descriptions identify
them as contribution workspaces; their website links lead to the contribution
index or to upstream PR history. Their upstream READMEs, licenses,
commit history, and contribution branches remain intact. Actual contributions are
presented through upstream PRs, commits, reviews, and reports in the evidence index.

This organization pass retains every fork, including all active contribution
workspaces. It does not close PRs, delete branches, rename upstream projects, or
add branding commits to their development branches. The tables cover the 36 public
forks visible in the 2026-09-28 repository snapshot.

## Preservation rules

An open PR or unpublished branch is a reason to retain a workspace, not to clean it
away. A merged or closed PR also remains part of the contribution record. No fork
is labelled inactive solely because it was not selected for the profile homepage.

GitHub repository lists are not folders: this index supplies a navigation layer
without transferring ownership or disturbing PR references. A public fork cannot
independently be made private; see GitHub's [fork visibility documentation](https://docs.github.com/en/pull-requests/collaborating-with-pull-requests/working-with-forks/about-permissions-and-visibility-of-forks).

Per-project PR searches may require GitHub sign-in. Direct, verified contribution
links are available in [UPSTREAM.md](UPSTREAM.md).
